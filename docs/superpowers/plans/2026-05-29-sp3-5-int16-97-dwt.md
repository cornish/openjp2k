# SP-3.5 — Int16 9/7 DWT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an AVX2 int16 Q1.15 path for the 9/7 lossy inverse DWT,
dispatched per-tilec when source precision ≤ 12 bits AND
`whole_tile_decoding` is true. Targets 8-bit lossy decode (WSI 1024²
tiles, photographic, 8-bit DICOM) with predicted +5–8% wall-clock gain
on those workloads; 12-bit lossy is also covered (smaller, secondary
gain).

**Architecture:** A new orchestrator `opj_dwt_decode_tile_97_int16`
parallels the existing float `opj_dwt_decode_tile_97`. It packs
`tilec->data` (int32) into a Q1.15 int16 scratch buffer (applying any
required `headroom_downshift` derived from component precision), runs
the inverse 9/7 lift in int16 across all decomposition levels using
horizontal and vertical AVX2 kernels (both vectorized — wider coverage
than grok), and at the final level performs a fused DC-shift + clamp
directly back into `tilec->data`. Lift uses Q1.15 throughout with
`_mm256_mulhrs_epi16` as the sole multiply primitive; |c| ≥ 1
coefficients (α, K, 2/K) are handled by additive decomposition (no
Q2.14 path). β uses a ×8 / >>3 precision boost. K and 2/K are fused
into the interleave phase. `opj_dwt_decode_real` chooses the
orchestrator based on `image_comp.prec`, `whole_tile_decoding`,
`__AVX2__` availability, and a process-local test override
`opj_dwt_force_float_97`.

**Tech Stack:** C99, x86 AVX2 intrinsics (`__m256i` carrying 16 int16
lanes), `_mm256_mulhrs_epi16` for Q1.15 rounding multiply,
`OPJ_ENABLE_AVX2` cmake gate (from SP3.1).

### Step 2: Add Q1.15 macros and constants near SP3.2's `VREG_S16` block

```c
#ifdef __AVX2__
/* SP-3.5: Q1.15 mirror macros for the 9/7 IDWT.  16 int16 lanes per
 * __m256i (vs 8 float lanes in the SP3.1 float lift).  Intermediate
 * state is Q1.15 throughout.  Coefficients with |c| >= 1 (alpha, K,
 * 2/K) use additive decomposition (see spec); only |c| < 1 fractional
 * parts go through the mulhrs primitive. */

/* The Q1.15 rounding multiply-high primitive (single VPMULHRSW).
 * Result = (a * b + 0x4000) >> 15, lane-wise on int16. */
#define MULHRS_Q15(a, b) _mm256_mulhrs_epi16((a), (b))

/* Q1.15 constants (round(c * 2^15) for the relevant fractional c). */
#define Q15_DELTA      ((int16_t)14533)   /* +0.443507  */
#define Q15_GAMMA      ((int16_t)28931)   /* +0.882911  */
#define Q15_BETA8      ((int16_t)13890)   /* +0.423841 = 8 * 0.052980 */
#define Q15_ALPHA_F    ((int16_t)19205)   /* +0.586134 = |alpha| - 1  */
#define Q15_K_F        ((int16_t) 7542)   /* +0.230174 = K - 1        */
#define Q15_INVK_F     ((int16_t)20506)   /* +0.625732 = 2/K - 1      */
#endif /* __AVX2__ */
```

The earlier draft proposed a Q2.14 path with a `MULHRS_Q14` macro.
**Do not add either.** They are mathematically incorrect and not
needed — the additive decomposition handles α and K/2/K cleanly. Step
0 (undo α) is `D[n] += sum + opj_q15_mul(sum, Q15_ALPHA_F)`; the interleave
K-scale is `x += opj_q15_mul(x, Q15_K_F)`. See spec § Per-step decomposition
strategies.

### Step 3: Add the pack / unpack helpers with `headroom_downshift`

```c
/* SP-3.5: Pack int32 -> int16 with optional headroom downshift in the
 * same pass.  Equivalent scalar:
 *   for each i: dst[i] = saturate_int16(src[i] >> headroom_downshift)
 * Vectorized via _mm256_packs_epi32 after an arithmetic right shift.
 * For prec == 8 / 10 the shift is 0 and this is a pure narrowing pack
 * — same shape as opj_dwt_pack_int32_to_int16_avx2 from SP3.2.
 * For prec == 12 the shift may be 1 (see spec § Headroom). */
static void opj_dwt_pack_int32_to_int16_q15(int16_t* dst,
                                             const OPJ_INT32* src,
                                             OPJ_SIZE_T n,
                                             int headroom_downshift);

/* SP-3.5: Unpack int16 -> int32 with optional left-shift reversal of
 * the headroom downshift.  Only used on the defensive fallback path;
 * the standard final-resolution path goes through the fused
 * DC-shift + clamp instead. */
static void opj_dwt_unpack_int16_q15_to_int32(OPJ_INT32* dst,
                                               const int16_t* src,
                                               OPJ_SIZE_T n,
                                               int headroom_downshift);
```

Implementation modeled directly on SP3.2's pack/unpack helpers
(~50 LOC each, AVX2 inner loop with scalar tail).

### Step 4: Add the horizontal int16 9/7 lift kernel

A single `opj_v16dwt_decode_step_h_int16_avx2` that processes one row
of int16 scratch through all four lift steps in the spec order:

1. **Step 3 (undo δ).** For each odd-indexed S-position (after the
   K/2-K interleave):
   `S[n] -= MULHRS_Q15(ADD(D[n-1], D[n]), SET1(Q15_DELTA))`.
2. **Step 2 (undo γ).** Same shape with `Q15_GAMMA`, opposite parity.
3. **Step 1 (undo β, ×8 precision boost).** For each S-position:
   ```
   prod0 = MULHRS_Q15(D[n-1], SET1(Q15_BETA8))
   prod1 = MULHRS_Q15(D[n  ], SET1(Q15_BETA8))
   S[n] += SRA_S16((prod0 + prod1 + SET1(4)), 3)
   ```
   `_mm256_srai_epi16` for the >> 3.
4. **Step 0 (undo α, additive decomposition).** For each D-position:
   ```
   sum  = ADD_S16(S[n-1], S[n+1])
   frac = MULHRS_Q15(sum, SET1(Q15_ALPHA_F))
   D[n] += ADD_S16(sum, frac)
   ```

The K / 2/K scaling is applied in the interleave helper (see Step 5).

Edge handling: symmetric mirror at the row endpoints (cleanroom §6
and spec § Edge handling). The first and last vector chunks of the
row need a scalar fixup; the middle vectors run pure AVX2. Special-
case `length == 1` (emit the single sample scaled by K or 2/K
according to parity, skip lift).

### Step 5: Add the horizontal interleave kernel with fused K / 2/K scaling

`opj_v16dwt_interleave_h_int16_avx2` gathers the strided low-band and
high-band samples into the contiguous scratch row, applying the K
scale to even samples and 2/K to odd samples via additive
decomposition during the gather:

```c
/* For even lane: scratch[i] = even_in[k] + MULHRS_Q15(even_in[k], Q15_K_F);
 * for odd lane:  scratch[i] = odd_in[k]  + MULHRS_Q15(odd_in[k],  Q15_INVK_F);
 */
```

Re-verify the choice between `1/K` and `2/K` matches openjp2k's
pre-DWT band normalization (the cleanroom note explicitly flags this
as a re-derivation point).

### Step 6: Add the per-row dispatcher and the temporary vertical scalar fallback

### Step 7: Add the orchestrator `opj_dwt_decode_tile_97_int16`

```c
#ifdef __AVX2__
static OPJ_BOOL opj_dwt_decode_tile_97_int16(opj_thread_pool_t* tp,
                                              opj_tcd_tilecomp_t* tilec,
                                              OPJ_UINT32 numres)
{
    /* Derive headroom_downshift from image_comp->prec:
     *   <= 10 : 0
     *   == 11 : 0
     *   == 12 : 0 or 1 (final value pinned at implementation time
     *                   based on empirical 12-bit measurement;
     *                   see spec Open Question #1)
     */

    /* Allocate int16 scratch via opj_aligned_32_malloc.
     * Pack tilec->data into scratch via opj_dwt_pack_int32_to_int16_q15
     * (applies headroom_downshift).
     *
     * For resno = 1 ... numres - 1:
     *   For each row: opj_dwt97_decode_h_func_int16
     *   For each col-stripe: opj_dwt97_decode_v_func_int16 (via job submit)
     *
     * At the final resolution, the scatter is replaced by the fused
     * DC-shift + clamp directly into tilec->data, with a left-shift
     * by headroom_downshift before the clamp.  For Task 1a this can
     * be a simple scalar loop; Task 1b replaces it with an AVX2 kernel.
     *
     * Free scratch.
     */
}
#endif
```

Body ~150 LOC, structurally similar to `opj_dwt_decode_tile_97`.

OPJ_BOOL opj_dwt_decode_real(opj_tcd_t *p_tcd, opj_tcd_tilecomp_t* tilec,
                             OPJ_UINT32 numres)
{
    if (p_tcd->whole_tile_decoding) {
#ifdef __AVX2__
        if (!opj_dwt_force_float_97) {
            const OPJ_UINT32 compno = (OPJ_UINT32)(tilec -
                                       p_tcd->tcd_image->tiles->comps);
            const opj_image_comp_t *image_comp = &p_tcd->image->comps[compno];
            if (image_comp->prec <= 12 && !image_comp->sgnd) {
                return opj_dwt_decode_tile_97_int16(p_tcd->thread_pool,
                                                    tilec, numres);
            }
        }
#endif
        return opj_dwt_decode_tile_97(p_tcd->thread_pool, tilec, numres);
    } else {
        return opj_dwt_decode_partial_97(tilec, numres);
    }
}
